常见问题

兼容哪些客户端？
任何支持 OpenAI API 格式的客户端均可接入：Cursor、Windsurf、Claude Code、ChatBox、LobeChat、NextChat 等。
支持哪些 AI 模型？
Claude (Anthropic)、GPT-5.x / o3 (OpenAI)、Grok (xAI)、Gemini (Google)、DeepSeek 等主流模型。
如何保障稳定性？
多账号池化 + 智能调度 + 健康检查 + 自动故障转移，单账号异常自动切换。
数据安全？
全程 HTTPS，不存储对话内容，仅记录 token 用量。API Key 加密存储。
