# v0.1.166 Release Conflict Resolution Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Merge Stable Release v0.1.166 into the production-approved custom branch, preserve custom gateway risk middleware and upstream panel rate limiting, repair conflict-base diagnostics, and publish the verified paired images through the durable two-phase release workflow.

**Architecture:** Keep the upstream and custom router behaviors in the single existing assembly point without redesigning Gateway ownership. Repair the diagnostic contract at both ends: the shell producer writes `conflict_base`, and the Vue consumer falls back to `base_commit` for historical jobs. Production remains behind the existing Actions, paired-image, backup, immutable-manifest, apply, health, and rollback gates.

**Tech Stack:** Git annotated Releases and worktrees, Go/Gin, Bash and jq, PowerShell contract tests, Vue 3/TypeScript/Vitest, GitHub Actions/GHCR, Docker Compose, systemd durable release jobs.
